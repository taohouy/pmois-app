### 1.2 API Test
- **GET /api/v1/workspaces**: เรียกใช้งานสำเร็จ — ส่งคืนรายการ Workspace ทั้งหมดที่ User มีสิทธิ์เห็น
- **GET /api/v1/projects**: เรียกใช้งานสำเร็จ — ส่งคืนรายการ Projects ที่ User มีสิทธิ์เห็นจาก Workspace Scope
- **POST /api/v1/workspaces**: สร้าง Workspace สำเร็จ — ตอบ JSON kพร้อมข้อมูลครบ (id, code, name, description, status)
- **POST /api/v1/projects**: สร้าง Project สำเร็จ — ตอบ JSON kพร้อมข้อมูลครบ (id, code, name, workspaceId, progress, health, current_milestone, profile_completeness_percent)
- **PUT /api/v1/workspaces/{id}**: อัปเดตสถานะ Workspace สำเร็จ — ตอบสำเร็จเมื่อส่ง `{status: 'active'/'on_hold'}`
- **Permission Test**: ยืนยันว่า API ทุก endpoint ตรวจสอบ Permission ผ่าน `PermissionResolver` และ `Workspace Scope` ครบถ้วน ไม่มีบั๊กการ绕过 Permission
